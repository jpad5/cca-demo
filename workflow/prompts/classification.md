# Classification node

**Input:** expression E2.1 (subject, body preview, attachment names).

| Category | Description |
|---|---|
| `ContentsInventory` | A policyholder or adjuster submitting a list of damaged, destroyed or lost household contents for a claim, usually as a spreadsheet attachment. |
| `ProofOfPurchase` | Receipts, invoices, order confirmations or other proof of purchase for specific items. |
| `Other` | Anything else: questions, complaints, status requests, newsletters or unrelated mail. |

Only `ContentsInventory` continues. Everything else is posted to the CAT Desk channel for triage.
